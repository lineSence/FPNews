# Шаг 10. Доказательная база: тексты правок, копии страниц, подписки

Шаг закрывает три пробела, которые мешают пользоваться архивом как источником: правку видно только по длине, исчезнувший материал не отличается от живого, а вопрос приходится задавать вручную каждый день. Этапы OSINT-плана 4–6 (сущности, связи, всплески) остаются на следующие шаги.

Ограничения площадки прежние: одно ядро, 500 МБ памяти, без JavaScript. Тяжёлые выборки — только по запросу и с потолком строк [CORE-025]. Наблюдение и машинная оценка разделены [NEWS-008]. В каждой строке — ссылка на оригинал [NEWS-007]. Отсутствие данных не равно нулю [NEWS-001]. Модели в горячем пути нет [NEWS-002].

Состояние на 25.09.2026: серверная часть написана и прогнана — `pytest -q` 123 passed, `pyflakes` чисто. Веб-страницы под новый каркас (сайдбар, светлая и тёмная темы) идут следующим заходом.

## 1. Тексты правок и диф

В `item_revisions` добавлена колонка `text` (через `LATE_COLUMNS`, базы на сервере мигрируют сами). `store.revise` принимает текст редакции, `store.revisions` отдаёт историю вместе с текстами.

Сравнение — отдельный модуль `news/diff.py`, чистые функции без базы:

```python
def parts(old: str, new: str) -> list[tuple[str, str]]   # («равно» | «убрано» | «добавлено», текст)
def markup(old: str, new: str) -> str                    # тот же диф в <del>/<ins>
def summary(old: str, new: str) -> dict                  # слов убрано, слов добавлено, знаков ±
def phrase(old: str, new: str) -> str                    # «−12 сл., +3 сл., −412 зн.»
```

Решения: сравниваем по словам, а не по буквам (побуквенный диф на русском даёт кашу из окончаний); всё чужое экранируется внутри `markup`; потолок `MAX_CHARS = 60 000` на сравнение — материалов длиннее у нас не бывает, а одно ядро считать две мегабайтные страницы не должно.

## 2. Копии страниц

Таблица `snapshots`: `item_id`, `taken_at`, `sha256`, `size`, `packed` (gzip исходного HTML), уникальность по паре `item_id + sha256` — одинаковая страница не хранится дважды.

- `store.save_snapshot(conn, item_id, page)` — при первом разборе (`run.handle`) и при каждом перечитывании.
- `store.snapshots(conn, item_id)` — список без тел, `store.snapshot_page(conn, id)` — сама страница.

Зачем: пересказ проверить нельзя, копию можно. Когда издание снимает материал, у нас остаётся то, что мы видели своими глазами, со временем получения и отпечатком [NEWS-007]. Цена — около 10–20 КБ на материал в сжатом виде; политика хранения та же, что у текстов: год.

## 3. Снятие с публикации

Колонки `items.gone_at` и `items.gone_code`. Перечитывание (`news/recheck.py`) теперь ходит через `article.load_page`, который отдаёт и код ответа, и исходный HTML.

- Ответ 404 или 410 (`GONE_CODES`) — `store.mark_gone`, и тем, кто получил первую версию, уходит досылка «Материал снят с публикации» с кодом ответа.
- 403, 429, 503 исчезновением не считаются: это защита сайта от нас, а не удаление текста [CORE-017].
- Страница снова ответила — `store.revive` снимает отметку.
- `gone_at` — время нашего наблюдения, а не момент снятия: между ними наш интервал перечитывания, и выдавать одно за другое нельзя [NEWS-001]. Первое наблюдение не переписывается.

## 4. Сохранённые запросы

Таблица `saved_queries`: запрос, фильтры (издание, тема, только оригиналы, только с правками), `notify`, `last_item_id`. Модуль `news/queries.py`:

```python
def fresh(conn, saved, limit=BATCH) -> list[dict]   # находки новее last_item_id
async def once(bot, conn) -> int                    # один обход всех подписок
async def loop(bot, conn, stop, every=300.0)        # фоновый контур
```

Решения: точка отсчёта — последний существующий материал на момент сохранения, иначе первая проверка вывалила бы весь архив [NEWS-004]; проверка — тот же FTS5-поиск, ноль обращений к модели [NEWS-002]; отправка через `deliver.send_to` с видом `запрос`, поэтому перезапуск процесса не пришлёт то же второй раз; потолок `BATCH = 5` находок за заход.

## 5. Тесты

`tests/test_news_diff.py` — разметка убранного и дописанного, исчезнувший абзац целиком, экранирование чужого HTML, счёт слов и знаков, потолок длины.
`tests/test_news_archive.py` — копия хранится и распаковывается, одинаковая не дублируется, 404 записывается и досылается, повторное снятие не шлёт второе сообщение, возврат страницы снимает отметку, 429 исчезновением не считается, перечитывание кладёт текст ревизии и копию.
`tests/test_news_queries.py` — подписка молчит о прошлом, новая находка уходит, повторный обход молчит, фильтр издания соблюдается, выключенное уведомление только отмечает, чужой запрос не удаляется, пачка ограничена.

## 7. Риски

- **Рост базы.** Копии страниц — самая тяжёлая часть шага. Смягчение: gzip, дедупликация по `sha256`, срок хранения год; после недели работы замерить и записать цифру в `docs/news-osint.md`.
- **Ложные исчезновения.** Издание может отдать 404 при сбое. Смягчение: отметка снимается автоматически при следующем успешном заходе, а досылка уходит один раз.
- **Шум подписок.** Слишком общий запрос («город») превращается в поток. Смягчение: потолок пачки и возможность выключить уведомления, оставив накопление.
