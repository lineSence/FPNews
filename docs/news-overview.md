# FPNews: обзор

FPNews собирает новости петербургских и федеральных изданий, отслеживает, кто написал первым и кто переписал, и отдаёт результат в Telegram и веб.

Проект выделен из FuckHR. Общего кода больше нет: в `main` только FPNews, старый код лежит в ветке `legacy` и используется как донор фрагментов.

## Поток данных

1. `news.fetch` + `news.sources` — получить список публикаций источника.
2. `news.article` — вытащить заголовок, лид, текст.
3. `news.store` — сохранить материал, посчитать simhash, записать ревизию при изменении.
4. `news.dedup` — найти повторы, проставить `dup_of`.
5. `news.story` — собрать сюжет по порогу похожести `FPNEWS_STORY_THRESHOLD`.
6. `news.enrich` / `news.embed` — опциональное обогащение и векторы.
7. `news.deliver` + `news.telegram` — отправка подписчикам по темам.
8. `news.web` + `news.pages` — веб-лента, задержки, темы.

Архитектура подробно: `docs/news-architecture.md`, схема БД: `docs/news-schema.md`.

## Состояние

Шаги 1–7 дорожной карты выполнены. Следующий — шаг 9 (OSINT-слой: поиск, страница материала, страница сюжета), затем шаг 8 (задержки). См. `docs/news-roadmap.md` и `docs/news-step9.md`.
