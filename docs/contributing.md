# Как вести код

- Язык комментариев и документации — русский, имена модулей и публичных функций — по месту, единообразно с соседями.
- Файл не длиннее примерно 25 КБ [CORE-024]; разрослось — делим по смыслу.
- Зависимости: в рантайме только `httpx`. Новая зависимость — отдельное обсуждение.
- Каждое изменение сопровождается тестом и, если меняется поведение, правкой документации в `docs/`.
- Коммит описывает результат, а не процесс.
- Фрагменты старого проекта берём из ветки `legacy` осознанно: переносим только нужное и сразу под правила FPNews, вместе с тестом.
- Правила предметной области — `wiki/rules/news.md`.
