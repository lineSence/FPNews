# Меню бота: всё управление кнопками

## Зачем

Команды с аргументами — это синтаксис, а не интерфейс. «Подпишитесь
командой `/подписаться meduza`» требует знать и команду, и код издания;
обычный человек закрывает чат. Шаг 19 переводит управление в меню
кнопок: экраны сменяют друг друга в одном сообщении, печатать нужно
только то, что нельзя выбрать кнопкой — и только в ответ на вопрос бота.

Команды при этом никуда не делись: кто привык печатать `/темы` или
`/сводка 09:00`, печатает по-прежнему. Меню — для остальных.

## Как это устроено

**Экран.** Текст и ряды кнопок. Нажатие перерисовывает то же самое
сообщение (`editMessageText`): чат не превращается в простыню. Если
телеграм отказал в правке — сообщение устарело или текст не изменился —
бот присылает новое.

**Данные кнопки** короткие и самодостаточные (`m:izd:meduza`,
`m:mode:meduza:всё`, `m:svodcas:09:00`): экран и всё нужное для действия
вшиты в кнопку, поэтому старые сообщения работают и после перезапуска
службы. Ограничение Telegram — 64 байта на данные нажатия.

**Диалог.** Слова темы, адрес сайта, имя для приглашения нельзя выбрать
кнопкой — бот спрашивает, и ближайший ответ человека становится ответом.
Состояние диалога живёт в памяти процесса десять минут; команда или
кнопка «Отмена» закрывают его сразу.

**Подтверждение.** Необратимое действие — удаление темы, остановка сбора
издания с подписчиками, удаление издания — сначала показывает, что
именно пропадёт и скольких это коснётся, и только второе нажатие
действует. Тот же принцип, что у страницы-подтверждения в вебе.

**Роли.** Владельческие экраны (каталог, доступы, состояние, хранение)
проверяют роль при каждом нажатии, а не полагаются на то, что кнопки не
было видно. Читателю нажатие отвечает «только владельцу» и ничего не
меняет.

## Экраны

| Кнопка | Что внутри |
| --- | --- |
| Мои издания | список изданий с текущим состоянием; у каждого — «всё / тишина / только темы», плюс «все издания сразу» |
| Мои темы | список тем; внутри — слова и стоп-слова диалогом, порог пресетом, вкл/выкл, удаление с подтверждением |
| Сводка | показать сейчас, час пресетом (07:00 / 09:00 / 19:00), выключить |
| Сообщения в бот | виды сообщений переключателями, тихие часы и задержка отдачи пресетами |
| Запросы | сохранённые запросы: новый диалогом, уведомлять/молчать, убрать |
| Найти издание | диалог «пришлите адрес» → общий каталог, выбор из него — личный |
| Каталог изданий (владелец) | состояние сбора, подписчики; остановка и удаление — с подтверждением, интервал пресетом |
| Доступы (владелец) | список приглашений; выдать диалогом (роль кнопкой), отозвать |
| Состояние (владелец) | материалы, база, задержки; «опросить сейчас» и проверка связи |
| Хранение (владелец) | размеры; выброс старых копий, сжатие базы |

В системном меню Telegram бот показывает четыре команды (`setMyCommands`):
`/меню`, `/помощь`, `/сводка`, `/вход`.

## Код

- `news/menu.py` — экраны, действия, диалоги и подтверждения; чистые
  функции, никакого сетевого ввода-вывода.
- `news/telegram.py` — `inline()` для клавиатур, `edit()` для
  перерисовки, `set_commands()` для системного меню.
- `news/bot.py` — `serve()` сначала предлагает сообщение меню (`/меню`
  и открытые диалоги), остальное уходит прежним командам; `press()`
  разводит кнопки `m:…` в модуль меню.

Тесты — `tests/test_news_menu.py`: 26 проверок, от «меню открывается
командой» до «остановка сбора с подписчиками требует подтверждения».
